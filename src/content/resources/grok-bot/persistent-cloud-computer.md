useCase: |
  Set up your cloud computer as my always-on workstation. Walk me through signing in to the tools I use every day, then configure it: keep my files and logins between sessions, use connectors and MCP where they're available and the browser and terminal everywhere else, and do the work inside the real tool rather than handing me a draft to move. Keep a running list of which apps you're signed in to and which files live on the computer, since every bot on my account shares them, and ask before storing anything sensitive. Ask me which tools to connect first, where project files should live, and what should never be saved on the machine, run the first task end to end with me watching, then save the setup.
